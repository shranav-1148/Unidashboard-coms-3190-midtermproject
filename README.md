## Project Description:

The website aims to provide all the information a prospective college student could need when deciding which college to apply and enroll in. The website aims to provide a completely unbiased view. The website will use data collected from the US department of Education and will remain completely unattached from journals and popular college ranking sources.

## Setup Instructions:

Start a Live server with index.html, which will load up the landing page of the website, The header and the footer has navigation elements to go to other webpages.

## Known Limitations:

For the purpose of the midterm, we couldn't implement the US Department of Education API, because it requires backend, so for now the data that is being displayed is a template generic data of colleges.
